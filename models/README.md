# Put your mods here

The studio comes with the game's human bodies, in `VanillaHumans`. To make skins for anything else,
copy the whole folder of a mod with the models you want into this folder, then click **Rescan** in the
studio. For example:

    steamapps/workshop/content/108600/3778832646/mods/XochisCustomBFT  ->  models/XochisCustomBFT

The main README has the details.
